# Guía del Itrio (Y, elemento 39)

Guía interactiva y gratuita en español para estudiar el itrio: historia, tabla periódica, átomo, configuración electrónica, propiedades, enlaces, laboratorio de masa molar, espectro de aplicaciones, extracción, semivida, juego de parejas, fichas con repetición espaciada, glosario y quiz de 30 preguntas.

Funciona sin conexión después de la primera visita y se puede instalar como app.
